# 카카오맵 설정 안내

공식 문서: <https://apis.map.kakao.com/web/guide/> · <https://apis.map.kakao.com/web/documentation/> · <https://developers.kakao.com/docs/ko/kakaomap/common>

> 카카오 공지: **2026년 7월 21일부터 카카오맵 API 사용 방법과 무료 쿼터 제공 방식이 변경**되었습니다 (devtalk.kakao.com/t/api/150222).
> 아래 메뉴 이름은 2026-10 기준 공식 문서에서 확인한 것입니다. 콘솔 화면이 바뀌었으면 공식 문서를 우선하세요.

## 1. 앱 만들기와 카카오맵 사용 설정

1. <https://developers.kakao.com> 로그인 → 내 애플리케이션 → 애플리케이션 추가
2. 앱 관리 페이지에서 **[카카오맵] > [사용 설정]** 의 **[상태]를 [ON]** 으로 변경
   - 사용 설정을 켜지 않으면 키가 맞아도 지도가 뜨지 않습니다.
   - **무료 쿼터는 개발자 계정에서 처음 활성화한 앱에만 제공**됩니다. 두 번째 이후 앱이나 무료 쿼터 초과 사용은 비즈월렛 연결과 유료 API 설정이 필요합니다(사용량 기반 과금). → **유료 전환은 운영 담당자 판단 사항이며 이 프로젝트에서 자동으로 켜지 않습니다.**

## 2. 키 구분

| 키 | 이 프로젝트에서 | 노출 |
|---|---|---|
| **JavaScript 키** | `VITE_KAKAO_MAP_JAVASCRIPT_KEY` — 지도 SDK, 관리자 장소 검색(services 라이브러리) | 브라우저 번들에 포함됨(정상). 도메인 제한으로 보호 |
| REST API 키 | 사용 안 함 | 클라이언트에 두지 말 것 |
| Admin 키 | 사용 안 함 | 절대 클라이언트·저장소에 두지 말 것 |

지도 SDK에 REST API 키를 넣으면 오류가 납니다.

## 3. 사용 도메인 등록 (JavaScript 키 도메인 제한)

JavaScript 키 설정의 **‘JavaScript SDK 도메인’** 에 지도를 띄울 주소를 등록합니다. 등록되지 않은 도메인에서는 지도가 뜨지 않습니다.

| 환경 | 등록 예시 |
|---|---|
| 개발 | `http://localhost:5173` (Vite), 필요 시 `http://localhost:8787` (운영 모드 로컬 확인) |
| 휴대폰 실기기 테스트 | `http://192.168.x.x:5173` (같은 와이파이의 PC IP) — 테스트 후 삭제 권장 |
| 운영 | `https://운영도메인` (예: `https://today.example.kr`) — **QR에 넣을 고정 도메인과 동일하게** |

- 프로토콜·포트까지 정확히 일치해야 합니다. `www` 유무도 별도 도메인입니다.
- 배포 미리보기 주소(예: Vercel preview)를 쓰면 그 주소도 등록해야 지도가 보입니다.

## 4. 쿼터·장애 확인

- 사용량: 앱 관리 페이지 **[통계] > [쿼터]** (월간·일간)
- 무료 쿼터를 다 쓰면 **429 오류**가 납니다. 이 경우 서비스는 지도 영역에 “지도를 표시할 수 없습니다” 안내를 띄우고, **목록·상세·카카오맵 길찾기 링크는 계속 동작**합니다(가짜 지도 이미지로 대체하지 않음).
- 이 서비스는 고객 방문 때 지오코딩/장소검색을 하지 않으므로(좌표는 관리자 등록 시 1회 확인) 호출량은 주로 지도 로드입니다.

## 5. 구현 메모

- SDK는 `src/lib/kakaoLoader.ts` 에서 `autoload=false` 로 **한 번만** 로드하고 `kakao.maps.load()` 콜백 이후에 지도를 생성합니다. React StrictMode·재렌더링에도 스크립트가 중복 삽입되지 않습니다. 10초 시간 초과 시 실패 처리 후 재시도 가능.
- 마커는 `CustomOverlay`에 DOM 요소(`textContent`)로 만들어 사용자 입력을 HTML로 해석하지 않습니다.
- 카카오 로고·저작권 표시는 지도 왼쪽 아래 기본 위치에 있으며, 화면의 버튼·패널이 덮지 않도록 배치했습니다.
- 길찾기는 공식 URL 규격 `https://map.kakao.com/link/to/{이름},{위도},{경도}` (이름 URL 인코딩), 검증된 장소 ID가 있으면 `https://map.kakao.com/link/to/{장소ID}` 를 사용합니다. 좌표 미확인 업소는 `link/search/{주소}` 로 연결합니다.
- 지도 타일·SDK를 오프라인 저장(서비스 워커 캐시)하지 않습니다.

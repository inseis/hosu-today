## 2026-10-19 추가 반영

- 서비스 이름 ‘호수원픽’으로 변경
- 장항동 참여 업소 67곳(상권 노트의 공개 항목만), 주변 주차장 23곳(카카오 주차장 카테고리, 요금·운영시간 미확인)
- 카스·카스 0.00·한맥 취급 업소 강조: 운영자가 제공한 제품 이미지(`public/images/brands`) 사용 — 카스 병, 카스 0.00 병, 한맥 병, 한맥 생맥주. 카스 생맥주 이미지는 미제공이라 아이콘 표시
- 노트의 ‘카스 0.0’ 기록은 운영자 확인에 따라 ‘카스 0.00 병’으로 등록
- ‘논알콜·무알콜’ 필터 추가(카탈로그 `nonAlcoholic` 제품 취급 확인 업소), ‘등록 영업시간 기준 운영 중’ 필터 칩 제거
- ‘뭐 먹을지 모르겠다면?’ 간단 추천: 업소명·업종 단어와 확인된 음료로 3곳 제안, 추천 이유 표시(규칙 기반, 인기·평점 미사용)

## 추가 설정이 있어야 하는 기능

| 항목 | 필요한 것 |
|---|---|
| **지도 표시·마커** | JavaScript 키 설정 완료. `localhost:5173`에서는 동작 확인. **GitHub Pages(`https://inseis.github.io`)는 카카오 콘솔 JavaScript SDK 도메인에 등록해야 지도가 표시됨** (미등록 시 카카오가 `domain mismatched` 401 응답 → 지도 대신 안내, 목록·길찾기는 정상) |
| 관리자 장소 검색(좌표·장소 ID 확인) | 위와 같은 JavaScript 키 |
| 실제 업소 데이터 | 업소 제공 정보 + 게시 동의 + 운영자 검토. 현재 **실제 업소 0곳** |
| 인쇄용 QR | 운영 고정 도메인(`VITE_PUBLIC_BASE_URL`) + 배포 |
| 배포 | 미배포. DEPLOY.md 참고 |
| 업소 사진 | 업소 제공 사진 URL. 없으면 ‘사진 준비 중’ |
| 공식 브랜드 로고 | 현재는 텍스트+아이콘 배지. 공식 파일을 받으면 `BeverageBadges`에서 교체 |
| 외부 분석 서비스 | 미연결. 이벤트 인터페이스(`src/analytics/events.ts`)만 교체하면 됨 |

## 알려진 한계

- GitHub Pages 배포: 서버가 없어 데모 데이터로 공개되며 관리자·제보·집계는 동작하지 않음. 직접 링크(`/venues/...`)는 `404.html`로 앱을 띄우므로 화면은 정상이지만 HTTP 상태 코드는 404.

- JSON 파일 저장소는 서버 1대 기준. 확장 시 DB 교체 필요.
- 공개 API는 60초 캐시 — 게시·수정 후 고객 화면 반영까지 최대 1분.
- 로그인 시도 제한은 메모리 기반이라 서버 재시작 시 초기화.
- Content-Security-Policy 헤더는 카카오 SDK 도메인 확인 후 운영 환경에서 추가 권장.
- Pretendard 글꼴은 jsDelivr CDN에서 불러오며, 실패 시 시스템 한글 글꼴로 표시.
